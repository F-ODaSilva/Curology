# Curology — product landing page (v2)

A React + Vite landing page that puts the products first, built with plain CSS (Tailwind removed). It keeps the original concept — the "Timeless Skin. Lush Hair. Beautifully You." hero, the tilted photo bento with coloured borders, the purple → pink → yellow glow, Coiny headings, Poiret One navigation, sky → indigo buttons and the horizontal product card with S / M / L sizes.

## Sections
Hero with email sign-up · About (original copy, card deck, grayscale image that colours on hover) · **pinned product lineup** that stages each bottle as you scroll · 3-question routine finder · shop with original product cards and sizes · before/after slider · how it works · reviews · FAQ · bag drawer with checkout.

## Run
```bash
npm install
npm run dev      # local development
npm run build    # static build in dist/ (relative paths, works from any folder)
```
All images live in `public/media` as WebP; product shots are cut out with soft natural shadows.
